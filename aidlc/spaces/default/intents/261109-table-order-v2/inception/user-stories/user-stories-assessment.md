# User Stories Assessment: Table Order v2

**Decision:** Execute.

**Rationale:** v2 adds 10 user-facing features across three kinds of user, and its rules (allergy warnings, options pricing, the staff PIN) need testable acceptance criteria.

**Factors considered:** a brownfield enhancement, user-facing scope on diner and staff screens, and shared live behaviour across devices.

**Where stories add the most value:** the Allergy shield's safety rules, the separation of diner and staff access, and what each 3D X-factor does when 3D can't run.

**Plan:** 2 personas are carried over from v1 and one is added, stories are broken down by feature, and every story is Must Have because the team confirmed all features as in scope. No questions were needed, because the requirements settle personas, breakdown and priority.
